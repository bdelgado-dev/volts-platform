A TECHNICAL-VOCATIONAL LEARNING PLATFORM

V.O.L.T.S.

Search real workshops for hidden tools, then use them to escape, build ladders, chairs, tables and more across 24 levels.

HOW TO PLAY

Finish all 6 Woodworking levels to unlock Welding, Electrical Installations and Project Making. Each tool you pick up teaches you what it is and what it is used for.

SETTINGS & CONTROLS

Movement

W / A / S / D - Walk

Arrow Keys - Walk

E / Space - Talk, enter door, use exit

B - Open / close bag details

1-9 - Select a tool in the bag

Esc - Pause

Tips

Stand next to furniture and press E to search it.

Some furniture is empty. Search them all!

Read each tool card. It is on the quiz.

The minimap shows where you are.

Progress saves automatically.
